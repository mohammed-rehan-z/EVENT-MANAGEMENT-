# Gemini / Agent Rules

- **Tech Stack**: Next.js (App Router), Supabase (PostgreSQL), Tailwind CSS, Shadcn/ui. MUI reserved only for heavy data grids.
- **Styling**: Prioritize modern, premium aesthetics. Use Shadcn components for consistency.
- **Data Fetching**: Use Next.js Server Actions for mutations and data fetching where appropriate to protect Supabase service keys.
- **Terminology**: Use generalized terms (`event_tracks`, `groups`, `participants`) instead of gaming-specific terms.
- **Scope**: Keep offline fallback (printable rosters) and payment screenshot verification top of mind.
